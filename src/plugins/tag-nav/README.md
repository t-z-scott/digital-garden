# Tag Navigation

Replaces the file tree with navigation grouped by tags.

A plugin for [Digital Garden](https://github.com/oleeskild/digitalgarden) sites.

## Install

Paste this repo's URL into **Settings → Digital Garden → Plugins → Install from GitHub** in Obsidian, or copy this folder into `src/plugins/tag-nav/` in your garden repo.

## Settings

- **Untagged group label** — Group name for notes without tags. Leave empty to hide untagged notes.

This plugin provides the **navigation** region. Only one navigation can be active: disable the built-in `dg-filetree` plugin (and any other navigation) after installing — the installer offers to do this for you.
