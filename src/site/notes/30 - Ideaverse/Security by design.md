Involving security in the design phase of a new service.
An product should be [[30 - Ideaverse/Secure by default\|Secure by default]] with additional security features (MFA, encryption, SSO, etc) included at no extra cost.

>[!idea] 
> Lower the vulnerability count as much as possible before the service is released for production use.
