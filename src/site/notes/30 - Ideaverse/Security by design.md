>[!idea] Main idea
> Security is embedded in the development workflow, not an afterthought.

## Definition
The principle of involving security in the design of a new service.

## Benefits
1. Allows you to react proactively to threats instead of being reactive.
2. Shrinks the service's attack surface.
3. Increases user trust.
4. Stops security from becoming the "department of no."

## How to implement
Threat model before the project is live, then again each time there's a system change.
